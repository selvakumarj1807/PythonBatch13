
Change the DB:
--------------

DATABASE_URL=mysql+pymysql://root:@localhost:3306/fastapi_demo

Install Depandency:
-------------------
python -m venv venv 

venv\Scripts\activate

pip install -r requirements.txt 

Run the Project:
----------------

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000


Run your Browser
----------------

http://127.0.0.1:8000


Useful FastAPI URLs
-------------------

| URL             | Purpose       |
| --------------- | ------------- |
| `/`             | Home API      |
| `/docs`         | Swagger UI    |
| `/redoc`        | Documentation |
| `/openapi.json` | API Schema    |
