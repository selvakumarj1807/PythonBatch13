Django + React Employee Project

PROJECT SETUP GUIDE

BACKEND SETUP (Django)

1.  Navigate to Backend folder:

    cd Backend

2.  Create virtual environment:

    python -m venv venv

3.  Activate virtual environment:

    Windows: venv\Scripts\activate

    Mac/Linux: source venv/bin/activate

4.  Install project dependencies:

    pip install -r requirements.txt

5.  Apply database migrations:

    python manage.py makemigrations
    python manage.py migrate

6.  Run Django server:

    python manage.py runserver

Backend will run at: http://127.0.0.1:8000/

FRONTEND SETUP (React)

1.  Navigate to frontend folder:

    cd employee-frontend

2.  Install node modules:

    npm install

3.  Start development server:

    npm run dev

Frontend will run at: http://localhost:5173/

IMPORTANT NOTES

-   Make sure Django backend is running before using frontend.
-   Ensure CORS is enabled in Django settings.
-   Use Python 3.x and Node.js 18+ recommended.
-   Always activate virtual environment before running backend commands.

API ENDPOINT

Employee API: http://127.0.0.1:8000/api/employees/

CRUD Methods: 
-------------

GET - Fetch Employees 
POST - Create Employee 
PUT - Update Employee 
DELETE - Remove Employee
